# NiceGUI 全局图表工具栏统一设计

## 背景

NiceGUI 工作台已经把二级页签左移，但 K 线相关页面仍存在同类布局问题：

- `市场地图 -> 指数K线` 和 `ETF数据 -> ETF行情` 的选择框、说明文字被 `justify-between` 拉到页面两端。
- 共享图表组件把图表标题、区间按钮、记录数拆成多行且分散对齐。
- 宽屏下首屏出现大块空白，图表被向下挤；窄屏下缺少统一的换行规则。

这类问题不是单页瑕疵，而是共享控件层和页面级工具栏规范不统一。

## 目标

1. 全局统一 K 线图表头，避免标题、记录数和区间控件漂散。
2. 统一 ETF/指数选择区的左对齐密集布局。
3. 让核心图表更早进入首屏。
4. 保持现有业务逻辑、数据读取和区间筛选行为不变。

## 采用方案

采用“共享图表头 + 页面选择区统一”的方案。

### 共享图表头

`render_ranged_lightweight_chart` 负责所有 K 线图的标题、记录数、区间按钮、自定义日期和图表渲染。

新的结构为：

- 一行紧凑图表头。
- 左侧显示图表标题和当前记录范围。
- 右侧显示区间切换按钮。
- 自定义日期控件只在选择 `自定义` 后显示，并靠近区间按钮。
- 不再为记录数单独生成一行右对齐工具栏。

### 页面选择区

ETF/指数 K 线入口页负责资产选择和页面说明。

新的结构为：

- 选择框左对齐。
- 说明文字作为同一组的低优先级提示，靠近选择框或在下一行显示。
- 不使用 `justify-between` 把说明甩到页面右侧。
- 宽屏下保持密集，窄屏下自然换行。

### 样式约束

- 业务工具栏默认左对齐、可换行。
- 只有顶栏等真正需要两端布局的壳层元素继续使用 `justify-between`。
- 图表头使用稳定高度和响应式换行，避免切换区间或显示自定义日期时造成大幅跳动。
- 不新增装饰性卡片或营销式视觉元素。

## 覆盖范围

必须覆盖所有调用 `render_ranged_lightweight_chart` 的 NiceGUI 页面：

- `市场地图 -> 指数K线`
- `ETF数据 -> ETF行情`
- `策略实验室 -> 运行回测 -> 单 ETF 手动回测`
- `策略实验室 -> ETF复盘`
- `策略实验室 -> 指数过滤实验`

## 非目标

- 不改 K 线数据生成、均线计算、交易标记或图表 tooltip。
- 不重做全部表单系统。
- 不调整 Streamlit 页面。
- 不改变导航结构和页面边界。

## 测试与验证

自动化测试：

- 增加图表组件布局测试，确认共享图表头包含新的样式类，并且不再使用图表内 `justify-between` / 记录数单独右对齐行。
- 增加页面级测试，确认 `市场地图` 和 `ETF数据` 的 K 线选择区不再使用 `justify-between`。
- 保留既有 chart range、record label、ECharts option 测试，确保区间筛选行为不变。

浏览器验证：

- 打开 `市场地图 -> 指数K线` 和 `ETF数据 -> ETF行情`，确认选择区、说明、图表头视觉关系紧密。
- 打开至少一个研究页 K 线场景，确认共享图表头同步生效。
- 检查桌面宽屏和窄屏视口，确认控件不重叠、不产生大面积空白。

## 验收标准

- 截图中的红框问题在全局同类页面消失。
- K 线页首屏图表明显上移。
- 图表标题、记录数、区间按钮形成一个清晰组件。
- ETF/指数选择区不再出现说明文字孤立漂到页面右侧。
- 现有测试通过，新增布局约束测试通过。

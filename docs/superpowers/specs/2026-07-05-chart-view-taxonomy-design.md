# 图表显示口径整理设计

研究与设计时间：2026-07-05

## 背景

当前图表显示口径包含五种选择：

- 线性坐标 Linear
- 涨跌幅视图 Return %
- 比例视图 Log Return %
- 回撤视图 Drawdown %
- 距区间低点 Downside %

这些口径本身都有价值，但在界面里平铺展示时会让用户误以为它们只是五种等价画法。实际使用中，它们分别服务于趋势观察、收益比较、风险观察和位置判断。

## 目标

把现有五种口径整理成更贴近个人投资决策的表达：

- 默认口径直接服务价格走势和买卖点观察。
- 收益比较口径突出“相对区间起点”的含义。
- 风险口径区分“相对前高回撤”和“回到区间低点还需要下跌多少”。
- 对数收益保留，但以高级口径命名，降低普通用户误用概率。

本次只调整已有口径的命名、排序和说明，不新增基准对比、不新增滚动窗口计算。

## 口径设计

推荐展示顺序：

1. 价格走势 Price
2. 累计涨跌幅 Return %
3. 回撤风险 Drawdown %
4. 回到低点需跌幅 Down to Low %
5. 对数收益 Log Return %

对应语义：

- `normal`：原始价格走势，适合看 K 线、均线、买卖点。
- `percent`：相对当前图表区间首个有效收盘价的累计涨跌幅，适合比较不同 ETF、指数或净值曲线。
- `drawdown`：相对此前最高收盘价的回撤，适合观察风险暴露和修复状态。
- `downside`：从当前价格回到当前图表区间最低收盘价仍需下跌的比例，适合判断是否仍靠近低位。
- `log_return`：相对当前图表区间首个有效收盘价的对数收益，适合长周期、等比例比较，作为高级口径保留。

## 暂不纳入

后续可以补充两类更有决策价值的口径，但它们需要额外输入，不放进本次小改动：

- 超额收益：需要选择基准，如跟踪指数、沪深300或中证全指。
- 滚动收益/滚动回撤：需要选择窗口，如 20 日、60 日、120 日。

## 验收标准

- 图表单选项使用新的五个标签和推荐排序。
- 帮助文案能解释每个口径的决策用途。
- 渲染层 series title 与 UI 标签一致。
- 现有口径计算结果不变。
- 图表相关测试通过。

# 官方指数估值页面设计

## 目标

为已由 Tushare `index_dailybasic` 验证覆盖的六个核心宽基指数，提供独立的官方直接估值页面和显式同步任务。页面仅展示原始静态 PE、TTM PE、PB 及其数据日期和来源，不生成估值判断、百分位、评分或交易结论。

## 范围

纳入指数固定为：上证指数（000001）、上证50（000016）、沪深300（000300）、中证500（000905）、深证成指（399001）、创业板指（399006）。

页面位于 `市场地图 -> 指数估值`，与现有只展示价格原子指标的 `指数体检` 完全分离。申万行业、港股和其他主题指数不显示为缺失项，也不进行成分股估值重建。

## 数据与同步

`TushareProvider` 新增官方指数估值读取能力，使用 `index_dailybasic` 查询每个受支持指数的 `pe`、`pe_ttm`、`pb` 和交易日期。返回结果进入已有的标准指数估值结构，并以 `tushare_index_dailybasic` 标记来源。

数据维护页新增持久化任务“同步官方指数估值”。首次执行下载每个受支持指数的全部可得历史；后续执行从本地缓存的最后交易日之后增量更新。任务结果逐指数记录已同步、无数据或失败及其原因。该任务不调用 AkShare，不为未支持指数创建空缓存。

页面只读取本地 Parquet 缓存；任何页面渲染、筛选或刷新均不得触发网络请求。若没有缓存，页面显示“尚未同步官方指数估值”并引导至数据维护；若 token 未配置、权限不足或请求失败，错误只出现在同步任务结果中。

## 页面呈现

页面顶部说明为“仅展示 Tushare 覆盖的六个宽基指数官方直接值”。主表按固定指数顺序展示：指数代码、指数名称、估值日期、静态 PE、TTM PE、PB、数据来源。

所有数值只格式化显示，不再计算 ERP、盈利收益率、历史分位或任何综合指标。页面不提供买卖参考、评分、排序结论或对未覆盖指数的推断。

## 错误与边界

- `index_dailybasic` 仅允许受支持的六个指数；其他代码返回明确的能力不支持结果。
- 每条缓存记录必须包含交易日期以及至少一个原始估值字段；空响应不覆盖已有成功缓存。
- 同步失败保留原有缓存，页面继续展示其已有数据及缓存日期，不把失败伪装为最新值。
- Tushare token 仅从运行时环境读取，不写入配置、任务结果、日志或界面。

## 验证

测试覆盖：Tushare 字段标准化与支持代码白名单；首次和增量同步、失败保留旧缓存、未支持代码；维护任务去重和结果；页面路由、缓存缺失状态、固定六行表格、中文数据来源及“页面不发网络请求”边界。

完成后运行相关聚焦测试及全量 `pytest`。可选的真实连通性验证仅在设置 `TUSHARE_TOKEN` 的本地环境运行，且不输出 token。
